# STL - Standard Template library
In C++ we have STL where all the data structure and related algorithms are available by C++ for developers. STL are library of generic classes and functions. It is vital for CP as it well tested standard components/ data structures and functions. It abide DRY principle. This will save tons of time while competitive programming.    
STL has the following components.    
1. Containers - This stores data such as array,vectors etc.    
2. Algorithms - This provide reusable algorithms/functions on containers such as swap,sorting,searching copying etc.   
3. Iterators - It is a pointer that points to an element in the container. It is handled just like a pointer. IT CONNECTS ALGORITHM WITH CONTAINERS.   
4. Functors
