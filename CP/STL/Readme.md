# STL - Standard Template library
In C++ we have STL where all the data structure and related algorithms are available by C++ for developers. STL are library of generic classes and functions. It is vital for CP as it well tested standard components/ data structures and functions. It abide DRY principle. This will save tons of time while competitive programming.      
```
STL = Container + Algo + Iterator +(Functor)
```
STL has the following components.    
1. Containers - This stores data such as array,vectors etc.    
2. Algorithms - This provide reusable algorithms/functions on containers such as swap,sorting,searching copying etc.   
3. Iterators - It is a Object that points to an element in the container. It is handled just like a pointer. IT CONNECTS ALGORITHM WITH CONTAINERS.   
4. Functors - Function as an object, similar to decorator in python 

### Containers
1. Sequence containers - Linear data storage such as array or vector or list or dqueue    
2. Associative containers - Direct access data type such as dictionary or map or multimap.  It is used for fast searching,insertion,deletion or access. They generally use tree or graph type data structure inside.    
3. Derived containers - are derived form of above containers such as dqueue can produce stacks(LIFO),queue(FIFO),priority queue etc. List makes LinkedList        
4. Unordered associated containers - direct access such as set or multi-set
