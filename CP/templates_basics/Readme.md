# Templates in C++
The true power of C++.
#### class -> object
#### templates -> class
Templates are also known as Generics or Generic classes. It is very important concept for competitive programming.   
Templates concept is foundation of DRY principle.    
Template is one class handling multiple data types. It is also known as parameterized classes. Hence we can do generic programming.   
Syntax 
```
template <class T>   // T can be int,float,chat or any other object
// This class below is representing many classes depending on data type passed to it.
class someClass{
    t* arr;
    public:
    some codes......
    .
    .
}
```     
C++ has its on Standard template library(STL) often used extensively in competitive programming.
