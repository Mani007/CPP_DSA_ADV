# Sorting Algorithms
Sorting is basic and crucial algorithms. 
eg. sort 16365    
ASC: 1 3 5 6 6    
DSC: 6 6 5 3 2    
Basic sorting algorithms and their analysis based on time & space complexity. Sorting also lay down the foundation for search algorithm such as binary search.    
### Analysis criteria for sorting algorithms   
1. Time complexity for n number of input.   
2. Space complexity for n number of input. (In-place sorting algorithm)  
3. Stability - When order is maintained with similar input - Very important criteria   
4. Internal(All data is loaded in memory) and external sorting algorithm  
5. Adaptive - already sorted algo take less time  
6. Recursive(uses recursion) and non-recursive sorting   

## Bubble sort
### Main objective is to send the biggest element at the last of the input. 
#### So it finds the first biggest element and send it to the last, then it finds the second biggest element and send it to the last and so on till all the elements are arranged. We can also do reverse bubble sort for descending order.
Algorithm uses n-1 passes to reach the sorting.
